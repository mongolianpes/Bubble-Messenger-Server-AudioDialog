# Bubble Audio Dialog
## Назначение
Микросервис для взаимодействия пользователей через аудио звонок в проекте [Bubble](https://github.com/mongolianpes/Bubble-Messenger-Server) <br>
Используется для создания, ручного и автоматического удаления аудио диалогов, обмена аудио сообщениями в реальном веремени

## Функционал
- Создание аудио диалогов
- Удаление аудио диалогов пользователем или автомаческое удаления после неактивно пользователей длительное время
- Обмен аудио сообщениями пользователей

## RPC запросы
```
service AudioDialogService {
  rpc CreateAudioDialog(CreateAudioDialogRequest) returns (CreateAudioDialogResponse) {}
  rpc DeleteAudioDialog(DeleteAudioDialogRequest) returns (DeleteAudioDialogResponse) {}
}
```
Подробнее в файле AudioDialog/proto/audiodialog.proto

## HTTP запросы
Запросы принимаются только по пути /exchangeaudio на порту 8080

Тело запроса должно содержать:
- "dialog_id": ID диалога 
-	"user_id": ID пользователя в диалоге
-	"message": байты аудио сообщения

Тело ответа содержит:
- map, где: ключ - это ID пользователя, а значение - это список стркутур АудиоСообщний
- структуры аудио сообщений содержат: "time" - время в формате Unix; "audio" - байты аудио сообщения

## Порты
Для корректной работы необходимо открыть порты:<br>
- 8080: для внешних REST запросов
- 8086: для взаимодействия между сервисами через gRPC
